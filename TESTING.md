# Проверка версии из App Store

Устанавливайте приложение только из https://apps.apple.com/app/id6809803122. Старый DMG для этой проверки не нужен.

Запишите модель Mac, версию macOS и номер версии/сборки приложения. Не публикуйте личный текст, пароли или содержимое буфера обмена.

1. Установка с нуля на Mac без прежней копии: приложение устанавливается, открывается, инструкция понятна.
2. Разрешения: пройдите штатную настройку доступа; после возвращения приложение показывает готовность. Проверьте повторный запуск.
3. В TextEdit выберите ABC, вручную наберите ghbdtn и пробел. Запишите результат. Проверьте ручное исправление и отмену сочетанием из настроек.
4. Повторите набор в Safari, Telegram и привычном редакторе. Запишите, где исправление не срабатывает или меняет правильное слово.
5. Скопируйте обычный текст с веб-страницы, затем повторите ввод в TextEdit. Проверьте, что буфер обмена сохраняется и вставка работает.
6. Проверьте выход из программы, повторный запуск и автозапуск, если он включён.
7. Обновление проверяйте только когда App Store предложит более новую версию. Настройки должны сохраниться; при отсутствии новой версии отметьте «не проверено».
