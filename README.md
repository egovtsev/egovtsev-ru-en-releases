## Установка и обновления версии из DMG

Нужны Mac с Apple Silicon и macOS 26 или новее. Скачай DMG, открой его и перетащи egovtsev.ru/en в «Программы». ZIP в составе выпуска используется для встроенного обновления; для обычной установки выбирай DMG. Для исправления текста требуется разрешение «Универсальный доступ».

Начиная со сборки 25, обновления доступны через меню ru/en → «Обновления…». Можно включить ежедневную фоновую проверку и установку после выхода из программы. Для более старой сборки нужен один ручной переход на новую версию.

Каждый архив и лента версий подписаны Ed25519. Программа проверяет подпись до распаковки. Проверка обновлений не отправляет набранный текст, словарь, статистику или идентификатор устройства; GitHub и его инфраструктура видят IP соединения и технический запрос.

## Статус версии из DMG

У этой сборки пока нет Apple Developer ID и нотариального заверения. macOS может предупредить при первом открытии и повторно попросить разрешение «Универсальный доступ» после обновления. Подпись Ed25519 проверяет происхождение обновлений и не заменяет заверение Apple.

Программа предоставляется по приложенной лицензии бесплатного использования тестовой версии. Компонент Sparkle распространяется по собственной лицензии, включённой в выпуск.
